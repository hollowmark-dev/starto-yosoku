# 回答の記録（Google Apps Script）の設置手順

クイズの回答を、Googleスプレッドシートに1行ずつ貯めるための設定です。

**設定しなくてもクイズは動きます。** `docs/config.js` の `endpoint` が空のままなら、
何も送信されず、エラーも出ません。あとから設定しても大丈夫です。

所要時間は10分ほどです。

---

## 1. スプレッドシートを作る

1. <https://sheets.new> を開く（Googleにログインした状態で）
2. 左上のファイル名を `STARTO推し予測 回答ログ` など分かる名前に変える

シートのタブ名は変更しなくて構いません。`responses` という名前のシートは、
最初の書き込みのときに自動で作られます。

## 2. スクリプトを貼る

1. そのスプレッドシートのメニューから **拡張機能 → Apps Script** を開く
2. `コード.gs`（または `Code.gs`）に最初から書かれているコードを**全部消す**
3. このフォルダの **`Code.gs` の中身を全部コピーして貼り付ける**
4. 左上の保存アイコン（💾）で保存

## 3. 動作確認（デプロイ前に1回やっておく）

1. エディタ上部の関数選択メニューで **`testAppend`** を選ぶ
2. **実行** を押す
3. 初回は権限の確認が出ます

   - 「このアプリは Google で確認されていません」と出たら
     **詳細 → （プロジェクト名）に移動（安全ではないページ）** を押す
   - これは自分で書いたスクリプトを自分のシートに対して動かすための確認です
   - **許可** を押す

4. スプレッドシートに戻ると `responses` シートができ、テスト行が1行入っています

うまくいったら、**そのテスト行は削除して構いません。**

## 4. ウェブアプリとしてデプロイする

1. エディタ右上の **デプロイ → 新しいデプロイ**
2. 左の歯車アイコン ⚙ から **ウェブアプリ** を選ぶ
3. 設定を次のとおりにする

   | 項目 | 選ぶもの |
   |---|---|
   | 説明 | 何でも可（例: `v1`） |
   | 次のユーザーとして実行 | **自分**（Me） |
   | アクセスできるユーザー | **全員**（Anyone） |

   > ⚠ **「次のユーザーとして実行」は必ず「自分」にしてください。**
   > 「ウェブアプリケーションにアクセスしているユーザー」を選ぶと、
   > 回答した人のGoogleアカウント情報が紐づいてしまいます。
   > このツールは匿名で記録する設計なので、それでは意味がなくなります。

4. **デプロイ** を押す
5. 表示される **ウェブアプリのURL** をコピーする
   （`https://script.google.com/macros/s/……/exec` という形）

## 5. サイト側に貼る

`docs/config.js` を開いて、コピーしたURLを貼ります。

```js
const CONFIG = {
  brand: "STARTO推し予測",
  siteUrl: "https://hollowmark-dev.github.io/starto-yosoku/",
  endpoint: "https://script.google.com/macros/s/ここがあなたのURL/exec"
};
```

保存してGitHubにプッシュすれば完了です。

---

## 記録される内容

1行が1セッションです。

| 列 | 内容 |
|---|---|
| `timestamp` | 受信時刻（**サーバ側の時刻**。送信側が名乗った時刻は使いません） |
| `picks` | 各問で選んだ顔のID（`g012` のような形）を空白区切りで |
| `oshi` | 入力された推しの匿名ID（`M007` のような形）。スキップ時は空 |
| `proposed` | お見せした3人の匿名ID |
| `completed` | 最後まで進んだか（1 / 0） |

## 記録されない内容

**IPアドレス・ブラウザの種類（User-Agent）・Cookie・Googleアカウント・参照元URLは保存しません。**

Apps Script の `doPost` にはそもそも送信元のIPやUAが渡されません。
そのうえで `Code.gs` は、受け取ったデータを**丸ごと保存するのではなく、
上の5項目だけを名指しで取り出して**書き込んでいます。
将来サイト側が余計な項目を送るようになっても、勝手に記録が増えることはありません。

IDの形式（`g000`〜`g999` / `M000`〜`M999`）に合わないものは捨てられます。

## 更新したとき

`Code.gs` を直したあとは、**デプロイ → デプロイを管理 → 鉛筆アイコン →
バージョン「新バージョン」→ デプロイ** としてください。
URLは変わらないので、`config.js` を貼り直す必要はありません。

（「新しいデプロイ」を選ぶとURLが変わってしまうので注意してください。）

## うまく動かないとき

- **シートに何も増えない**
  → `config.js` のURLの末尾が `/exec` になっているか確認してください。
  `/dev` で終わっていると、自分以外からは書き込めません。
- **デプロイ設定を間違えた**
  → 「デプロイを管理」から同じデプロイを編集すればURLは維持されます。
- **記録を止めたい**
  → `config.js` の `endpoint` を `""` に戻せば送信しなくなります。
